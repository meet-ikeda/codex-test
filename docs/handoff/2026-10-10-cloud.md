## 3. 調べたこと（出典つき）

**WikiSkill**（https://github.com/Stahl-G/wikiskill 。論文 arXiv:2608.27454 は本文未読）
- 記録 → Wiki（育つノート） → Skill（手順）の 3 層。手順は検証用の課題で良くなったときだけ変える。採らなかった変更も教訓は Wiki に残す
- オーナー: 「マニュアルとノートに分けた」のが exobrain の設計と似ている
- 別の実装の README に「実際の AI で検証を通った手順の変更は、まだない」（https://github.com/ashutoshsinghpr7/wikiskill ）

**AGENTS.md を自動で育てる人が少ない理由**
- AI に書かせた AGENTS.md は成功率 0.5〜2% 低下・費用 20% 以上増。人が書いても +4% ほど（ETH チューリッヒ、arXiv:2602.11988）
- WikiSkill はまだ新しく、検証用の課題を作るのが大変

**Hindsight**（https://github.com/vectorize-io/hindsight 、MIT。ドキュメントは同リポジトリの `hindsight-docs/docs/developer/`）
- AI 用の記憶サーバー。Docker か pip で動く。API はポート 8888、画面は 9999。MCP あり。PostgreSQL（pgvector）を使う。Ollama でも動く
- 層: 事実（書き換えない）／見立て observation（考え 1 つにつき 1 件。根拠の引用と数を持ち、上書きせずに強める・弱める・広げる。前の版も残る）／理解 mental model（人が決めた質問 1 つにつき文書 1 枚。新しい記憶が来たら変わった部分だけ直す）
- mental model は、exobrain の案件ノートに近い
- memory bank（記憶の部屋）を、人・エージェント・プロジェクトごとに分けられる
- LongMemEval で 91.4%（Gemini-3 Pro。論文 arXiv:2512.12818）。会社のサイトでは 94.6%（自社発表。第三者の確認は見つからず）
- 日本語での精度は未確認

**記憶のベンチマーク**
- LongMemEval（ICLR 2025。500 問。取り出す・会話をまたぐ・時間・知識の更新・答えない の 5 つ。https://github.com/xiaowu0162/longmemeval ）
- LoCoMo（ACL 2024。とても長い多回の会話。https://github.com/snap-research/locomo ）
- どちらも英語で「会話の事実を覚えているか」を測る。「案件の続き」「理由から考え直す」を測るものは見つからなかった

**CLAUDE.md・AGENTS.md・自動メモリ**（https://code.claude.com/docs/en/memory 、https://developers.openai.com/codex/guides/agents-md ）
- Claude Code は `CLAUDE.md` がないときだけ `AGENTS.md` を読む。`CLAUDE.md` に `@AGENTS.md` と書けば両方から 1 か所を読める
- Claude Code の自動メモリは、ローカルでは最初から入。`~/.claude/projects/<project>/memory/` に置かれ、その Mac の中だけ

## 5. アバターごとの脳（池田コピー課）

オーナーの意図: 池田コピー課のアバターそれぞれの脳を、exobrain とは別に持たせたい。

- **できる:** `EXOBRAIN_HOME`（脳の場所）・`EXOBRAIN_DRIVE`（本棚の場所）・`exobrain app --port` で、別の脳として動かせる（`config.py`・`cli.py`）
- **そのままだと困ること:**
  - 毎晩の日報が、Mac の中の会話を全部読むので混ざる
  - install（常駐・睡眠・AI への登録）が 1 つの脳を前提にしている
  - 主語がオーナーで作ってある
  - アバターの数だけ睡眠が走る
- **やり方の候補:**
  - A: exobrain を丸ごと増やす（重い）
  - B: 1 つの exobrain の中で脳を部屋に分ける
  - C: アバターの脳は Hindsight の memory bank に任せる
- 大脳皮質の記憶によると、コピー課は「個人の教訓と課の共有知を分ける」「コピーライターは個人記憶を別々に持つ」設計
- **返事待ち:** アバターの脳に何を覚えさせたいか。コピー課のアプリが今どこまで記憶を持っているか
