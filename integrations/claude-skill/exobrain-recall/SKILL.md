# exobrain で思い出す

exobrain は、オーナー（池田さん）の、複数の AI で共有する外部脳。オーナーは「思い出したとき」と「思い出さないとき」の答えを比べたいので、この合図があったときだけ読む。

## 手順
1. exobrain の `start_session` を `include_profile=true` で呼ぶ（ai_name は自分の名前。例: "Claude"）。返ってきた profile（オーナーのルールと知識）を読む
2. 直前の話題（オーナーの最後の相談）を短い文にして、`recall` の cue に渡す
3. profile と recall の結果を踏まえて、直前の相談に答え直す
   - recall の結果に記録の引用があれば、日時・書き手・出典を添える
   - 「確認できる記録はありませんでした」と返ったら、以前に聞いた・決めたとは言わない
4. 最初に「exobrain から思い出しました」と一言添え、何を踏まえたかを短く示す

この会話では以後、話題が変わったら recall を呼んでよい。

exobrain の道具が見つからないときは、「exobrain につながっていないため思い出せませんでした。この会話で exobrain のコネクタがオンになっているか確かめてください」と伝える。
