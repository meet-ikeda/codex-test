# exobrain に預ける

exobrain は、オーナー（池田さん）の、複数の AI で共有する外部脳。この会話をそこへ預ける。

## 1. 受付で確かめる（郵便の受付のように）
次の3つが会話から明らかでなければ、預ける前にオーナーに短く聞く。明らかなら聞かない。
- 取材の会話か（書かれた体験・意見は取材相手のもの） → note_type = "interview"
- クライアントについての話か → note_type = "client"
- 外に出したくない内容か → confidential = true（本棚にだけ置かれ、大脳皮質には移らない）

## 2. まとめる
- 対象は、この会話のうち、前に預けた（deposit を呼んだ）あとの部分だけ。初めてなら会話全体
- summary: 何の会話か、数行
- procedural（手続き記憶）: やり方・ルール・好み・オーナーから注意されたこと
- semantic（意味記憶）: 事実・決定・オーナーがいま取り組んでいる仕事・考えていること・関心
- episodes（エピソード記憶）: 出来事（いつ・何があったか）
- どれも 1 項目 1 文。会話にあったことだけを書く。推測で足さない
- 誰の話かを主語で書く（「取材相手の〇〇さんは…」「A社は…」「オーナーは…」）
- 電話番号・住所・メールアドレス・パスワードなどは書かない

## 3. 送る
exobrain の `deposit` 道具を呼ぶ（session_id がなければ `start_session` を include_profile=false で呼んで受け取る。記憶は読まない）。
返ってきた message_to_user を、そのままオーナーに伝える。

exobrain の道具が見つからないときは、「exobrain につながっていないため預けられませんでした」と伝え、代わりにまとめた内容をそのまま表示する。
