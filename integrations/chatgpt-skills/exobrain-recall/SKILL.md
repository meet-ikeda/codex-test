# exobrain で思い出す

exobrain は、オーナーが Codex・Claude・ChatGPT などで共有している外部脳。オーナーは「思い出したとき」と「思い出さないとき」の答えを比べたいので、合図があったときだけ読む。

## 読み方（上から順に試す）

1. **exobrain の道具（MCP）が使えるとき**（Codex など）
   - `start_session` を `include_profile=true` で呼ぶ（ai_name は自分の名前）。返ってきた profile を読む
   - 直前の話題を短い文にして `recall` の cue に渡す。会話の id は `exo_session` という名前で渡す
2. **道具がないとき**
   - Google ドライブで「exobrain」フォルダ →「大脳皮質」フォルダ →「大脳皮質.md」を探して読む。見つかれば、その中の手続き記憶・意味記憶・エピソード記憶のファイルも必要に応じて読む
3. **どちらもできないとき**
   - 「exobrain を読めませんでした。Finder で マイドライブ/exobrain/大脳皮質/大脳皮質.md をこのチャットに添付してください」と伝える

## 答え方

- 最初に「exobrain から思い出しました」と一言添え、何を踏まえたかを短く示す
- 記録にないことを「前に聞いた」「前に決めた」とは言わない
- 記録が古そうなときは、いつの時点の記録かを添える
